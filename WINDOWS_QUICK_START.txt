RAAHI PROPERTY SCRAPER — WINDOWS TEST BUILD

Target: Windows 10/11 x64. Python does not need to be installed.
Use your normal Windows account and Google Chrome 96+ with extensions permitted.
This is an unsigned test build. Client browser verification testing is pending.

START
1. Extract the ZIP to a folder and open RaahiScraper.exe.
2. Open your usual Google Chrome and select your normal profile.
3. In Raahi, click Browser Connector Setup. In chrome://extensions, enable
   Developer mode, click Load unpacked, and choose the extension folder shown
   by Raahi. This enables this locally supplied extension in your normal profile.
4. Click the Raahi extension icon, paste the pairing code copied from Raahi,
   and click Connect. The pairing code is remembered on this computer/account.
5. Click Check eAuctionsIndia Browser Access. Complete any Cloudflare human
   verification yourself in the auction tab.
6. Keep Chrome, its connector tab and auction tab open. You can minimize Chrome.
   Raahi reuses the website session without exporting cookies. After restarting
   Raahi, the open connector tab reconnects automatically to the same app pairing.

ALTERNATIVE: Chrome 144+ supports direct connection without the extension.
Open chrome://inspect/#remote-debugging and enable remote debugging; click
Check eAuctionsIndia Browser Access in Raahi and allow Chrome's prompt.
Chrome 136-143 does not support this direct connection to its normal profile.
Very old Chrome versions and managed profiles that forbid both connection
methods are unsupported. Update Chrome or ask your browser administrator.

EXPORT
Select a source and states, start scraping, select properties, then Download
Selected. Scraping collects image/document URLs only. With Download Images and
Notices with Excel checked, Excel is saved first, then files are saved locally.
Default export folder: %LOCALAPPDATA%\RaahiScraper\Exports
You can choose another writable output folder in the app.
Photos are in propertyImageUrls; notice images are in noticeImageUrls.
Some auctions publish only notices and have no actual property photos.

WINDOWS ACCEPTANCE TEST
1. Select only eAuctionsIndia and Tripura + Sikkim as a small first sample.
2. Confirm normal Chrome is used and no separate browser/profile is created.
3. Confirm property details, notice URLs and available photo URLs appear in Excel.
4. Confirm files download only at export, and image/notice files open correctly.
5. Run another scrape with Chrome and Raahi still open; the auction tab is reused.
6. Restart Raahi while leaving Chrome and its auction tab open. Allow reconnection
   if Chrome asks, and confirm the same auction tab is reused.
7. Test BaankNet and the other required source/state selections.
8. Check that errors/failed attachments produce a warning and permit retry.

Verification can expire or be invalidated by the website. Raahi waits for manual
verification and resumes; unpublished photos cannot be provided by the scraper.
Disconnect Chrome releases the direct connection and leaves Chrome open.
For extension mode, click Pause in the connector tab, or close that tab.

BUILD EVIDENCE
windows-packaging-check.json records automated frozen-app validation on Windows:
GUI initialization, bundled Playwright driver and extension, file locking and
Excel roundtrip.
build-info.json and SHA256SUMS.txt identify the source and executable.
These automated checks do not replace the live client Chrome acceptance test.
