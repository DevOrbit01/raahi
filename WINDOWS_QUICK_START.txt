RAAHI PROPERTY SCRAPER — WINDOWS TEST BUILD, NO EXTENSION

Windows 10/11 x64. Python and Chrome extensions do not need to be installed.
Use your normal Windows account and Google Chrome.
This is an unsigned test build. Live client browser verification is pending.

START
1. Extract the ZIP and open RaahiScraper.exe.
2. Select eAuctionsIndia and your states. Click Start Scraping.
3. If the browser connection is missing, Raahi opens the connection settings
   page in normal Chrome. Enable Allow remote debugging if the option exists.
4. Click Check eAuctionsIndia Browser Access. Allow Chrome's connection prompt.
5. Complete any Cloudflare human verification manually in the auction tab.
6. Keep Chrome and that auction tab open. Raahi reuses the browser session across
   states and later scrapes. Reconnection may need Chrome approval again.

BROWSER COMPATIBILITY
Raahi does not reject Chrome by its version number. Chrome must expose a
compatible approved browser connection. The normal-profile permission UI was
introduced in Chrome 144. If it is missing, update Chrome. Chrome 136-143 does
not expose that UI and restricts remote debugging the default profile through
command-line flags. Accepting a version number does not add this browser feature.
Older Chrome with an already-exposed compatible CDP endpoint can be attempted;
every Chrome version has not been tested. No extra browser/profile is launched.

CONNECTION ERRORS
Missing connection permission, invalid connection file, and unreadable Chrome
files are reported separately. Run Chrome and Raahi under the same Windows
account. Do not run one as a different user. If a connection becomes stale,
restart Chrome, re-enable its browser connection permission and retry.

EXPORT
Select returned properties, then click Download Selected. Scraping collects
image/notice URLs only. With Download Images and Notices with Excel checked,
Excel is saved first and images/notices are downloaded afterward.
Default output: %LOCALAPPDATA%\RaahiScraper\Exports
Photos: propertyImageUrls. Notice images: noticeImageUrls.
Some auctions publish only notices; unpublished photos cannot be scraped.
Failed attachments produce a warning and can be retried.

ACCEPTANCE TEST
Start with Tripura and Sikkim, then Gujarat and other required selections.
Confirm details/URLs in Excel, images/notices open, repeat scrapes reuse Chrome,
and restart Raahi with the auction tab left open to test session reconnection.
Website verification can expire or be invalidated and require another manual
verification. These live Windows checks remain pending.
